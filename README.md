# ai4biological-pattern

This repository contains the code used to carry out the Master's Thesis called "Explainability-Driven Deep Learning for Predicting Biological Invasiveness in Plant Species" by Barbara Frittella and Guido Spina. 

Due to technical necessities the work was developed in different branches

- Code written and developed by Frittella can be found in the branch "clean-barbara"

- Code written and developed by Spina can be found in the branch "guido-clean"

The thesis (identical in content but different in title due to copyright reasons) can be downloaded at the following links:

- Frittella - [Explainability-Driven Deep Learning for Predicting Biological Invasiveness in Plant Species](https://webthesis.biblio.polito.it/37834/)
- Spina - [XAI Tools to Predict Biological Invasiveness: a Case Study in Plants](https://webthesis.biblio.polito.it/37875/)
